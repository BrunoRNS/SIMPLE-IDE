Notes
-----

- The Linux binaries are BusyBox 1.20.0 builds. The source archive names record
  the Simple IDE-specific build options.
- The macOS binaries report BusyBox 1.20.0.git. The build date distinguishes the
  Intel and Apple Silicon source trees.
- The Windows binaries are busybox-w32 builds. The FRP marker and Git revision
  come from the busybox-w32 project.
- The same Windows source archive is used for the x86, x64 Unicode and ARM64
  executables.
- Update this file whenever a binary or its source archive changes.
